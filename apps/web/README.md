# Jornada Web

Frontend `PWA` do `Jornada`.

Base atual:

- `Vite`
- `React`
- `React Router`
- `React Aria Components`
- `Tailwind CSS`
- `vite-plugin-pwa`

Primeiras entregas visuais:

- shell de `auth`
- login
- cadastro
- recuperar senha
- redefinir senha
- area logada inicial com agenda, vencimentos e comunicados
